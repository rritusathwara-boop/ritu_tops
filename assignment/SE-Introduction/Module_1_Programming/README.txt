File extensions were selected according to each task:
- .c = C programming tasks
- .js = JavaScript tasks
- .py = Python file-handling tasks where the task specifically uses Python-style file modes/keywords
- .txt = short written answers, algorithms, setup instructions, and task requirements
- .docx = document-style answers and diagram guidance

For Session 1 Task 3, the Word file gives the exact flowchart sequence and symbol instructions; the actual drawing can be recreated on paper or draw.io.
